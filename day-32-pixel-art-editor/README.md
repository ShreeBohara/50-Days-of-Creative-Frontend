# Day 32 - Pixel Art Editor

A React + Canvas pixel art editor for the 50 Days of Creative Frontend series.

## Features

- Selectable 16x16, 32x32, and 64x64 canvas grids with grid toggle, zoom, and pan.
- Pencil, eraser, eyedropper, fill bucket, line, and rectangle tools.
- DB32 palette, custom hex input, recent colors, and current color preview.
- Up to four layers per frame with visibility, opacity, delete, and reorder controls.
- Animation frames with duplicate/delete, looping preview, FPS control, and onion skin.
- Mirror mode, 50-step undo/redo, keyboard shortcuts, PNG export, spritesheet export, and GIF export.

## Local Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The Vite base path is configured for GitHub Pages at `/50-Days-of-Creative-Frontend/day-32-pixel-art-editor/`.
